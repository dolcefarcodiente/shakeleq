# Сайт-портфолио — Janibek Shakeleq

Статический сайт: `index.html` + `styles.css` + `script.js` + `works.js`. Без сборки, без фреймворков.
Открывается двойным кликом по `index.html` или любым хостингом статики (Netlify, Vercel, GitHub Pages, Cloudflare Pages — всё бесплатно).

## Что внутри
- **Hero** — заголовок, подзаголовок, две кнопки, одна «главная» работа.
- **Works / Opere** — сетка работ с фильтрами (Все / Живопись / Рисунки / Этюды / Доступные), подпись как музейная этикетка: название, год, техника, размер, статус. Клик открывает лайтбокс (стрелки ← →, Esc).
- **Commissions / Ritratti su commissione** — 5 шагов, три формата, «цена по запросу».
- **About / Biografia** — биография + таблица (образование, город, выставки).
- **Contact / Contatti** — email, Instagram, форма (открывает почтовый клиент).
- **EN / IT** — переключатель в шапке, язык запоминается. Все тексты в `script.js` в объекте `I18N`.
- Тёмная тема включается автоматически по системной настройке.

## Как добавить работы (главное)
Сейчас в `images/works/01–10.jpg` и `images/about/studio.jpg` лежат **временные** фото из Instagram в 640 px.
Для сайта этого мало: на большом экране они будут мылить. Их нужно заменить на оригиналы с теми же именами.
1. Положи фото в `images/works/` с именами `01.jpg`, `02.jpg`, … (длинная сторона 2000–2400 px, JPG качество 80 — достаточно).
2. В `works.js` для каждой работы заполни `title`, `medium`, `size` (сейчас стоит `— × — cm`), `year`, `status`, `ratio` (пропорция фото, например `3/4`).
   Если файла нет, на его месте рисуется цветная заглушка в палитре картины (поле `ph`).
3. `featured: true` — какая работа стоит на главном экране.
4. Фото мастерской → `images/about/studio.jpg`.

Статусы: `available` (Disponibile), `sold` (Venduto), `enquire` (Su richiesta), `nfs` (не продаётся).

## Что нужно подтвердить у художника (я это написал как черновик, не как факт)
- Сроки заказа «4–8 недель», аванс 50%, страхованная доставка, сертификат подлинности, «ограниченное число заказов в год» — это стандарт по рынку, но он должен согласиться.
- Минимальные форматы (30×40, 60×80, 100×150) — заменить на его реальные.
- Цены: сейчас «по запросу». Если он готов показать «от €…» по форматам — это повышает конверсию (единственный итальянский сайт с открытыми ценами выглядит честнее всех).
- Названия работ — я дал рабочие названия по мотивам; его названия подставить в `works.js`.
- Выставки в разделе About — пустая строка `— to be added —`.
- Имя. Сайт сейчас под его именем, как в Instagram. Если нужен псевдоним — заменить в `index.html` (3 места: `<title>`, `.wordmark`, футер) и в `I18N` (`about.p1`).

## Форма
Сейчас форма — `mailto:`, т.е. открывает почту пользователя. Чтобы письма приходили без почтового клиента,
зарегистрируй бесплатный Formspree (formspree.io), и замени в `index.html` у `<form>` атрибут
`action="mailto:..."` на `action="https://formspree.io/f/XXXX"` и `method="post"`, а `enctype` убери.

## Публикация за 5 минут (Netlify)
1. app.netlify.com → Add new site → Deploy manually → перетащить папку.
2. Подключить домен (например `janibekshakeleq.com` или `shakeleq.art`).
